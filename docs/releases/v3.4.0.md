# Registry Add-On Release 3.4.0

## Changelog

- Updated Harbor to version 2.13.2.
- Updated the Kustomization examples to use modern Kustomize. This was developed using features from kustomize 5.6.0 and may not work in previous versions of Kustomize.
- Fixed the Kustomization `external-db` example: added missing configuration for the `exporter` component

## Upgrade path

### Pre-upgrade

* Backup the database that Harbor is using underneath.
* If you are using an external database, make sure the version of PostgreSQL is >= 12.

### Upgrade

Download new module's version, then apply the `kustomize` project.

> [!WARNING]
> If you are using v3.2.0 or lower, check all past release notes for upgrade procedures.
