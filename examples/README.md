# Example Deployments

Here you can find some examples of different kinds of deployments for the Harbor package.

| Example                    | Description                                                                                                |
| -------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [full-harbor](full-harbor) | Full in-cluster Harbor Installation.                                                                       |
| [harbor-ha](harbor-ha)     | Full Harbor installation, using external Database engine and Redis instances instead of the provided ones. |

If you need to migrate your deployment type from `full-harbor` to `harbor-ha`, you can read the [Harbor Full to HA Migration Guide](../docs/operations/full-to-ha-migration.md).
